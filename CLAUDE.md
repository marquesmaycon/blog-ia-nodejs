## Fluxo de commits

- Ao terminar qualquer alteração no código, sempre sugira os commits a realizar: mensagem no padrão Conventional Commits (em português) e os arquivos/hunks de cada um.
- Nunca execute `git commit` (nem `git push`) sem pedir permissão explícita antes. A sugestão é obrigatória; a persistência só acontece após o "sim" do usuário.
- A permissão vale apenas para os commits apresentados naquele momento, não para alterações futuras.
